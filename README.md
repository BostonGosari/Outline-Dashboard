# 🏃🏻‍♀️ OUTLINE Dashboard

> Interactive dashboard for managing art categories and courses. Built with React, Redux Toolkit, and Firebase.

## 🚀 Features

- 🖼️ **Course Management**: Add, view, and filter art courses by categories.
- 🔍 **Search Functionality**: Search courses by name.
- ⚙️ **Category Editor**: Edit categories and manage associated courses.
- 🌐 **Firebase Integration**: Syncs real-time data using Firestore and Firebase storage.

## 🛠️ Tech Stack

- **Frontend**: React, Redux Toolkit, Styled Components, motion-framer
- **Backend**: Firebase (Firestore & Storage)
- **Routing**: React Router
- **State Management**: Redux Toolkit
